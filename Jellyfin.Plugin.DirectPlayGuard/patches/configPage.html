Transcoding policy

Block CPU/GPU-heavy re-encoding while keeping lightweight remux/direct-stream available unless Strict Direct Play is enabled.

Recommended: leave this off. Remuxing/direct stream keeps the original codecs and is far lighter than transcoding.

Unsupported-client popup

Customize the message Jellyfin Web shows when a client cannot play the original media. GIFs stay animated because the original uploaded file is served directly.

Use one app per line. Lines like Computer: Jellyfin Media Player are automatically formatted into clean label/value rows.

Image / GIF

Use an uploaded PNG, JPG, GIF, or WebP, or point to an HTTPS image URL. Uploaded files are stored in Jellyfin's data directory so plugin updates do not delete them.

Used only when Image source is set to Image URL.
PNG, JPG/JPEG, animated GIF, or WebP. Maximum 10 MB.

Popup appearance

Uploaded GIFs are not converted or resized by the server, so animation is preserved. The popup only constrains the display size in CSS.
Native client limitation: Direct Play Guard can block transcoding for every client, but this custom popup is for Jellyfin Web and webview-based clients. Native TV/mobile apps normally use their own playback-error UI.
